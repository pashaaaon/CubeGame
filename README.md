# CubeGame

****This game is an independent project inspired by Minecraft and developed using my own graphics engine (https://github.com/pashaaaon/OpenGL-Graphics-Engine).****

**Extract the ZIP archive from the latest release before launching the game**

## Controls
- **WASD:** walk
- **Space**: jump
- **R:** respawn
- **Esc:** quit
- **LMB:** destroy a cube
- **RMB:** place a cube
- **J:** save map
- **L:** load map
